06 / Method06 / 方法

Three rules I do not bend.三条不让步的规则。

01 / MEASUREMENT

If you cannot reproduce it, it is not a result.复现不了，就不是结果。

Every number needs n, a condition set and a failure taxonomy. A number without evidence is a story.每个数字都要有样本量、条件集与失效分类。没有证据的数字只是故事。

02 / SIMULATION

Simulation is an instrument.仿真是仪器。

Renderer, camera, physics and protocol are part of the measurement. Calibrate the stack before comparing the model.渲染、相机、物理、协议都是量测的一部分。先校准仪器，再比较模型。

03 / BOUNDARIES

Say what is not covered.把没覆盖的说清楚。

No dyno-grade actuator identification, no whole-body locomotion, no production fleet claims. The boundary is part of the claim.不做 dyno 级执行器辨识、不做整机行走、不声称产线级集群。边界本身就是声明的一部分。

07 / Long line07 / 长期主线

This is the work, not a phase.这是长期要做的事，不是一段经历。

Embodied AI is the line I am staying on. The stack will keep changing — models, simulators, hardware — so the useful asset is not a tool list, but a way of working that keeps producing evidence.具身智能是我要长期做下去的主线。模型、仿真器、硬件都会换，所以真正有用的不是工具清单，而是一套持续产出证据的工作方式。

That is why this page is built as an archive, not a portfolio: dated entries, explicit gaps, and a weekly radar that keeps the map honest.所以这一页做成档案而不是作品集：条目带日期，缺口写在明处，每周雷达让地图保持诚实。
