How the layers connect

The interfaces are the job.

01 / DATA → MODEL

Schema is a contract.

If the dataset schema, quality grade, and license are not explicit, training is noise with a nice loss curve.

02 / SIM → EVAL

Simulation is a ranking tool.

It can screen and rank; it cannot sign. The real machine and the protocol gate decide what ships.

03 / DEPLOY → DATA

Field data compounds.

The only data that improves the loop is the data from a robot doing the job — including its failures and interventions.
