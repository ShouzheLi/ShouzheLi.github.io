4D from one camera.

Estimate camera pose, object geometry and interaction trajectories from a single video, replay the motion in Newton, and clean up editable assets in Blender.

  • Role4D reconstruction
  • StackPose solve · Newton · Blender · differentiable rendering · Python
  • StatusPersonal project · GitHub pending
中文摘要从单目视频估计相机位姿、物体几何与交互轨迹；Newton 运动学回放，Blender 整理可编辑资产；桌面 223 帧、储物柜 221 帧两个实例，含实物与回放的拖拽对照。

01Problem

One moving camera, occlusion and no depth. The output must be a trajectory that can be replayed, not just a mesh that looks right in one frame.

02Approach

01 / POSE

Recover the camera.

Estimate poses and scale from the capture before touching object geometry.

02 / TRACE

Track the interaction.

Recover object geometry and motion, then replay the trace in Newton.

03 / CLEAN

Make it editable.

Rebuild the asset in Blender so the result is a usable scene, not a frozen clip.

04Boundary

  • —Two scenes only; not a general reconstruction benchmark.
