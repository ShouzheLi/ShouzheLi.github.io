A data flywheel for soft objects.

Built the infrastructure for deformable manipulation: capture, reconstruct, generate, train and evaluate in one loop.

中文摘要主导建设柔性物体操作数据飞轮基础设施，打通“采集→重建→生成→训练→评估”全链路。

01Problem

Deformable objects break the usual data loop: reconstruction, simulation and training each assume a different asset form, so the handoffs leak.

02Approach

01 / CAPTURE

Start from real cloth.

Capture and reconstruct deformable state instead of approximating it with rigid proxies.

02 / GENERATE

Simulate the variation.

Generate manipulation episodes in Isaac Sim and Newton under a shared asset contract.

03 / CLOSE

Feed training and evaluation.

Export to training and evaluation through one interface so failures return to the loop.

03Result

5
