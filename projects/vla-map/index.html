中文摘要把 8 条 VLA/策略路线画在同一骨架上：输入 → 骨干 → 动作头 → 输出。核心主张是差别只有两件事——动作怎么表示、块有多长。公开事实、一手经验、判断分三区显示，判断带推翻条件。

01Problem

01 / MIXED

Claims and measurements share a table.

Vendor numbers, benchmark scores and our own runs usually sit in one row, so a reader cannot tell what was measured and under which protocol.

02 / FLAT

Every model looks different.

Papers describe architectures in their own vocabulary, which hides the fact that most routes share the same input-backbone-head structure.

03 / UNRUN

Unrun models read as tested.

A model listed next to a model we have deployed implies equal evidence, which is exactly the failure this page is meant to prevent.

03Boundary

  • —Five of the eight routes are public facts only; no first-hand claim is made for them.
  • —The nine-task set is labelled ICRA here; an internal record says ICAR, and the naming is unresolved.
  • —The improvement magnitude of our post-training run is not archived, so no number is given.
  • —Closed models (pi*0.6, pi0.7) remain public claims; no access, no measured comparison.
