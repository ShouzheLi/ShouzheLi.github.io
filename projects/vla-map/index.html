中文摘要把 8 条 VLA/策略路线画在同一骨架上：RT-2、OpenVLA、ACT、Diffusion Policy、π0 / π0.5 / π*0.6 / π0.7、GR00T N1.7。核心主张是差别只有两件事：动作怎么表示、块有多长。A 区公开事实、B 区一手经验（3/8）、C 区判断带推翻条件。

01Problem

Model comparisons usually mix vendor claims, benchmark scores and hands-on experience in one table, so a reader cannot tell which statement is measured and which is marketing.

02Approach

01 / SEPARATE

Three evidence zones.

Public facts, first-hand experience and judgment are visually separated, and every judgment carries a falsifier.

02 / GRAMMAR

One architecture skeleton.

Input, backbone, action head, output. Colour only marks the action head, so the eight routes can be compared on one axis.

03 / HONEST

Mark what was not run.

Models we have not run are grey and dashed; hands-on coverage is stated as 3 of 8, not implied.

03Result

8

Models

Eight routes drawn on the same skeleton.

52 KB

Single file

No scripts, no external requests, no internal paths.

3/8

Hands-on

Only the models actually run are presented as experience.

04Boundary

  • —Five models are public facts only; no first-hand claim is made for them.
  • —The ICAR versus ICRA naming of the nine-task set is unresolved.
  • —The improvement magnitude of our post-training run is not archived; no number is invented.
  • —Closed models (pi*0.6, pi0.7) are marked as public claims only.
