Personal project · 2026.11

RL vs imitation, then a second engine.

A Franka reach task trained two ways — PPO from scratch and behaviour cloning with two DAgger rounds — then replayed in Newton with the same ONNX to see which policy survives a different physics engine.

  • RoleRobot learning & evaluation
  • StackIsaac Sim / Lab · rsl_rl · PyTorch · ONNX · Newton
  • StatusPersonal project · reproducible
中文摘要Franka reach 任务的两条学习路线：PPO 从零训练、BC + 两轮 DAgger；再把同一 ONNX 放进 Newton 做同初态跨引擎验证。PPO 位置误差 3.33 cm、succ@5 89.0%；BC3 7.38 cm、29.7%；跨引擎后 PPO 5.66 cm / 98.4%，BC3 23.21 cm / 15.6%。

01Problem

Imitation usually looks better on the training distribution. The question is whether it survives a different simulator, and whether a longer RL run is actually better.

02Approach

01 / EXPERT

Build an IK expert.

Stiff PD plus damped least squares, with action clipping to remove singular outliers before collecting 91.9k transitions.

02 / LEARN

PPO and BC + DAgger.

PPO for 800 iterations at 1024 envs; BC followed by two DAgger rounds on the same task.

03 / TRANSFER

Replay in Newton.

Export one ONNX and run 64 paired initial states in Newton, same policy, different engine.

03Result

3.33 cm

PPO (iter 200)

succ@5 89.0%, succ@10 99.8%; the final iteration is worse, so the checkpoint was chosen by measured error.

5.66 cm

PPO in Newton

succ@10 98.4% after the engine swap.

23.21 cm

BC3 in Newton

succ@10 15.6% — closed-loop RL transfers, open-loop BC does not.

04Boundary

  • —No vision input and no contact or grasping; the task is end-effector reach.
  • —Newton pairing covers 64 initial states, not a full benchmark.
  • —Local RTX camera rendering crashes, so videos are joint-trajectory replays.
  • —BC still trails the IK expert by about 1.4 cm; a third DAgger round was not run.
