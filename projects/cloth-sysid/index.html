Fitting cloth without gradients.

A Real2Sim system for fabric physics: simulate, compare, and search parameters with gradient-free optimizers.

中文摘要从 0 到 1 搭建柔性面料 Real2Sim 高精度物理仿真与参数优化系统；用无梯度优化搜索参数，虚实对齐精度提升约 20%。

01Problem

Cloth parameters are expensive to evaluate and awkward to differentiate. A fitting loop has to work with a noisy, non-differentiable objective.

02Approach

01 / HARNESS

Fix the evaluation.

One repeatable sim-real comparison before any search, so the objective cannot drift.

02 / SEARCH

Go gradient-free.

Optuna, CMA-ES and Ray Tune over a bounded parameter space, with the same harness for every trial.

03 / CHECK

Hold out a case.

Keep a case out of the fit to catch a parameter set that only works on the tuning scene.

03Result

~20%

Alignment gain

Reported improvement in sim-real alignment.
